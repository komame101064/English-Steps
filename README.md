# English Steps

日本語話者のための英語入門アプリ。基本11000語と、そのレベルで使える定番フレーズ120を、音声つきで学びます。

- 画面構成は Thai Steps に合わせています：ホームは英語辞書と、単語・フレーズ・文法・復習の進み具合（円グラフ）の一覧。単語ページに今日の学習・単語／口語・ネットの切り替え・レベル・テーマ・一覧から練習
- 今日の学習（1ステップ10語：見る → 英→日 → 日→英、間隔をあけた復習）。口語・ネットの語は今日の学習に含めず、別の欄で学ぶ
- レベル：基本＝中学1年・初級＝中学3年・中級＝高校・上級＝大学以上。各単語の `lv`（1〜4）で決まり、`words.json` はレベル順（学習もこの順）。ホームにレベル別の進み具合、単語一覧でレベル別に絞り込み。レベルはAIが学校の学習段階を目安に判定したもので、教科書の公式語彙表との照合はしていません
- 辞書：ホーム上部と画面右上の「辞書」から、全レベルの単語とフレーズを英語（went→go、gave up→give up のような変化形も）・日本語・ひらがなの読みで検索。最近の検索を表示
- 文法：基本〜上級の全37課。解説・型（主語・動詞…で表示）・音声つき例文・練習問題5問。最高点を記録
- 単語：「一覧」と「テーマで学ぶ」。一覧はレベル・テーマ・品詞で絞り込み、学ぶ順／ABC順／未学習を先に で並べ替え。テーマはピクトグラムのタイルと進み具合、テーマ内のステップ・カード・テスト
- 単語カード：英語を見て思い出し、裏返すと意味と例文。「もう一度」は後ろにもう一度出す（最大2回）
- 復習登録：単語の「復習」ボタン（☆とは別）で復習に入れる。復習で正解すると外れる
- 例文の単語：単語ページでは例文中の語を押すとその単語を開く（変化形も元の語へ）。学習中は押すと発音
- スピードゲーム（復習タブ）：60秒で英→日の4択、コンボで加点、ベスト記録を保存
- 文法：練習問題を全問正解すると履修済み。間違えた問題は記録し、その問題だけやり直せる
- 設定：1ステップの語数（5／10／20）、自動で発音する／しない
- 単語一覧（検索・テーマ別）、フレーズ、テスト（英→日・日→英・聞き取り）、復習、お気に入り
- 音声はブラウザの読み上げ（en-US）。学習記録はこの端末のブラウザに保存（書き出し・読み込み可）

## 動かす

```
npm start   # http://localhost:8080
npm test
```

公開：`main` に push すると GitHub Actions が `site/` を GitHub Pages に配置します（Settings → Pages の Source を「GitHub Actions」に）。

## データ

- `site/data/words.json`：11000語（レベル順、意味・発音記号・品詞・レベル・例文と訳）
- `site/data/phrases.json`：120フレーズ
- `site/data/grammar.json`：文法37課（id g01〜g37 は学習記録のキー）
- `site/data/ja-readings.json`：辞書のひらがな検索用の読み（画面には出さない）。単語を追加・修正したら `pip install pykakasi` のうえ `python3 tools/build-ja-readings.py` で再生成。読みは自動変換なので一部不正確なことがあります（誤りやすい語は同スクリプトの `IRREGULAR` で補正）

単語（201語目以降）・フレーズ・文法の課はAIが作成したもので、ネイティブ話者の確認は受けていません。
