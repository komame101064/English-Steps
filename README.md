# English Steps

日本語話者のための英語入門アプリ。基本2000語と、そのレベルで使える定番フレーズ120を、音声つきで学びます。

- 今日の学習（1ステップ10語：見る → 英→日 → 日→英、間隔をあけた復習）
- レベル：基本＝中学1年・初級＝中学3年・中級＝高校・上級＝大学以上。各単語の `lv`（1〜4）で決まり、`words.json` はレベル順（学習もこの順）。ホームにレベル別の進み具合、単語一覧でレベル別に絞り込み。レベルはAIが学校の学習段階を目安に判定したもので、教科書の公式語彙表との照合はしていません
- 単語一覧（検索・テーマ別）、フレーズ、テスト（英→日・日→英・聞き取り）、復習、お気に入り
- 音声はブラウザの読み上げ（en-US）。学習記録はこの端末のブラウザに保存（書き出し・読み込み可）

## 動かす

```
npm start   # http://localhost:8080
npm test
```

公開：`main` に push すると GitHub Actions が `site/` を GitHub Pages に配置します（Settings → Pages の Source を「GitHub Actions」に）。

## データ

- `site/data/words.json`：2000語（レベル順、意味・発音記号・品詞・レベル・例文と訳）
- `site/data/phrases.json`：120フレーズ

単語（201〜2000語目を含む）・フレーズはAIが作成したもので、ネイティブ話者の確認は受けていません。
